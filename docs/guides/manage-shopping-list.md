# Add and remove shopping list items

## Add an item

1. Click **Shopping list** in the header.
2. Under **Add item**, enter an **Ingredient**, for example `Tomatoes`.
3. Enter an **Amount**, for example `6`. If you leave it empty, the amount is set to 1.
4. Click **Add item**.

The item appears at the bottom of **Items**, and both fields are emptied. To empty the fields without adding anything, click **Clear**.

## Remove an item

1. Find the item under **Items**.
2. Click **Remove** next to it.

When the last item is removed, the list shows "Your shopping list is empty."
